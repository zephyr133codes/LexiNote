**开发状态：** 已完成当日目标

## 一、今日开发目标

1. 搭建 Android 开发环境。
2. 初始化 LexiNote Android 工程。
3. 配置 Gradle 和 Java 开发工具链。
4. 完成首次 APK 编译。
5. 在 Android 真机上安装并运行应用。

## 二、今日完成内容

### 1. 项目初始化

- 确定项目名称：LexiNote。
- 建立项目目录和基础文档。
- 使用 Android Studio 创建 Empty Activity 工程。
- 选择 Kotlin 作为开发语言，Jetpack Compose 作为 UI 框架。
- 配置应用包名 `com.lexinote.app`。
- 设置最低 Android SDK 为 API 26。

### 2. 开发环境配置

- 配置 Android Studio 和 Android SDK。
- 使用本地 Gradle 9.6.0 发行包解决下载缓慢问题。
- 排查系统 Java 26 与 Gradle Daemon 所需 Java 25 的环境差异。
- 确认 Android Studio 内置 JBR 25，并调整 Gradle 相关配置。
- 成功执行 `gradlew.bat tasks --all`。

### 3. APK 构建

执行命令：

```powershell
.\gradlew.bat :app:assembleDebug
```

构建结果：

```text
BUILD SUCCESSFUL in 3m 33s
36 actionable tasks: 36 executed
```

成功生成 Debug APK。

### 4. 真机运行

- 开启 Android 手机开发者模式及 USB 调试。
- 通过 ADB 成功识别 Android 设备。
- Redmi K50 Ultra 首次安装遇到 `INSTALL_FAILED_USER_RESTRICTED`。
- 改用小米 15 Pro 进行测试。
- ADB 安装返回 `Success`。
- 手机成功启动应用并显示 `Hello Android!`。

**结论：Android 工程的编译、打包、安装和运行流程已经验证成功。**

## 三、今日遇到的问题及解决方式

| 问题 | 处理方式 |
|---|---|
| Gradle 下载速度缓慢 | 浏览器下载 ZIP，配置本地发行包 |
| Gradle 尝试下载 Java 工具链 | 检查 JDK 版本，使用已有 Java 25 环境进行配置 |
| Android Studio 无法识别构建任务 | 使用命令行 Gradle 独立验证工程 |
| 首次构建等待较长 | 等待依赖下载和构建完成 |
| PowerShell 无法识别 adb | 使用 adb.exe 完整路径 |
| Redmi K50 Ultra 拒绝安装 | 切换小米 15 Pro，安装成功 |
